An original open-world crime game, playable in a desktop browser from static files. Entry for [Make GTA 6](https://make.fun/bounty/gta6-01) (make.fun, $1,666 in USDC).

You are Mara Voss, a driver in debt to Rook. Explore the city of Porto Verde — four districts, a plaza, parks, landmark towers — on foot and by car, take on three story missions, dodge the police, and survive the night.

## Run it

Open `game/index.html` in desktop Chrome, or build the output with `node main.ts` (Node 22, standard library only).

## Controls

- **WASD / arrows** — move / drive
- **Shift** — run
- **Mouse** — look
- **E** — enter/exit car, talk, enter interiors
- **F** — punch
- **R** — reload
- **H** — horn
- **Q** — radio
- **Tab** — map
- **M** — mute

## Features

- 14×14-block city with four districts, traffic, pedestrians with day/night routines
- Wanted system (0–5 stars) with roadblocks and lose-the-cops
- Three story missions, street events, collectible Verde Coins
- Interiors: El Faro restaurant and Sunray Garage
- Day/night cycle, three radio stations, save/continue
- Side Jobs, gang territories, riots and stealable race cars

All content is original — own city, characters, names, story, art and sound.
